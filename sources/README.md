# 🔎 Источники

## Правила

1. Приоритет — первоисточникам и официальным публикациям.
2. Для важных событий желательно подтверждение несколькими независимыми источниками.
3. Дата и ссылка на источник указываются в каждой новости.
4. Факты отделяются от предположений и комментариев.
5. Для быстро меняющихся событий информация должна перепроверяться перед публикацией.
