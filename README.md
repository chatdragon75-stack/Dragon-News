# 🐉 Dragon News

Центральный архив новостей проекта о драконах, фэнтези, искусстве, технологиях и других интересующих темах.

## 📰 Основные категории

- 🐉 Драконы, фэнтези и книги
- 🎨 Арт, иллюстрации и художники
- 🤖 ИИ и технологии
- 💻 Программирование и GitHub
- 🌍 Важные мировые новости
- 🎮 Игры
- 📱 Приложения и гаджеты

## 📁 Структура

```text
news/       — отдельные новости по категориям
daily/      — ежедневные сводки
sources/    — источники и правила проверки
archive/    — архив старых выпусков
.github/    — автоматизация проекта
```

## 🎯 Цель проекта

Создать удобный, структурированный и проверяемый архив новостей с кратким содержанием, контекстом, датой публикации и ссылкой на первоисточник.

## 🔎 Принцип работы

Каждая новость должна по возможности содержать источник, дату, категорию и краткое объяснение того, почему она важна.
